GESTOR FINANCEIRO PESSOAL - BRUNO LEONIS

Arquivos:
- index.html
- style.css
- app.js

Como usar:
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html no navegador.
3. Os dados são salvos no LocalStorage do navegador.

Observação:
- Esta é uma versão local, sem login e sem banco de dados online.
- Para usar em vários dispositivos, o próximo passo é conectar a um backend/banco de dados.

Atualização:
- Dívidas/empréstimos agora aceitam parcelamento, vencimentos mensais e controle de parcelas pagas/pendentes.

Atualizações:
- Parcelamento de empréstimos/dívidas com valor original, valor por parcela, juros/acréscimo e status de cada parcela.
- Tema visual azul e preto.
- Favicon personalizado incluído.

Atualização de metas:

- Metas financeiras agora aceitam aportes posteriores.
- Botão "Adicionar valor" aumenta a meta sem mexer no saldo.
- Botão "Usar saldo atual" cria uma saída no financeiro e adiciona o mesmo valor à meta.
- Metas podem ser editadas depois de cadastradas.
- Histórico dos últimos aportes é exibido em cada meta.
